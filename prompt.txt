## 【四、Literal F1 指标】

1. 定义完全基于字符串匹配的边级 F1：

   ```python
   def literal_f1(gold: OntologyGraph, pred: OntologyGraph) -> Tuple[float, float, float]:
       gold_edges = {(gold.nodes[e.src], gold.nodes[e.tgt]) for e in gold.edges}
       pred_edges = {(pred.nodes[e.src], pred.nodes[e.tgt]) for e in pred.edges}

       tp = len(gold_edges & pred_edges)
       fp = len(pred_edges - gold_edges)
       fn = len(gold_edges - pred_edges)

       prec = tp / (tp + fp + 1e-9)
       rec  = tp / (tp + fn + 1e-9)
       f1   = 2 * prec * rec / (prec + rec + 1e-9)
       return prec, rec, f1
   ```

2. 这个函数需要在 `main()` 中被调用，并将结果打印出来。

## 【五、Fuzzy F1 指标（边级，基于节点语义相似度 + 阈值）】

1. Fuzzy F1 的思路：如果预测边 `(u,v)` 的两端节点，在 gold 图中都能找到语义非常相似的节点（相似度 ≥ 阈值），就认为这条预测边“匹配上了”一条 gold 边。

2. 简化实现版（你可以这样实现）：

   * 为 gold 节点构建 embedding 矩阵；

   * 写一个内部函数 `best_sim(node_id_pred)`，返回该预测节点与所有 gold 节点的最大余弦相似度；

   * 对每条预测边，计算：

     * `s1 = best_sim(e.src)`
     * `s2 = best_sim(e.tgt)`
     * 如果 `min(s1, s2) >= threshold`，则认为 TP++;

   * recall 的分母用 `len(gold.edges)`，precision 分母用 `len(pred.edges)`。

3. 函数形态例如：

   ```python
       pred: OntologyGraph,

   ) -> Tuple[float, float, float]:
       ...
   ```

   你可以适度优化（例如缓存相似度），但请保持逻辑清晰。

## 【六、Continuous F1 指标（边级 + Hungarian + soft TP）】

1. Continuous F1 的思路：

   * 对每条预测边 `e_p` 和每条 gold 边 `e_g`，计算一个连续的相似度分数 `sim_edge(e_p, e_g)`；
   * 用 Hungarian 算法在边之间做一一匹配，使总相似度最大；
   * 将匹配到的相似度和作为 soft TP；
   * 定义 soft precision、soft recall，再算 F1。

2. 边–边相似度可以仅基于两端节点的相似度（简单实现）：

   ```python
   def edge_similarity(
       e_p: Edge,
       e_g: Edge,
       pred_vecs: Dict[str, np.ndarray],
       gold_vecs: Dict[str, np.ndarray],
   ) -> float:
       up, vp = pred_vecs[e_p.src], pred_vecs[e_p.tgt]
       ug, vg = gold_vecs[e_g.src], gold_vecs[e_g.tgt]

       s1 = min(cos_sim(up, ug), cos_sim(vp, vg))
       s2 = min(cos_sim(up, vg), cos_sim(vp, ug))  # 如果愿意允许两端对调
       return max(s1, s2)
   ```

3. Continuous F1 实现示例：

   ```python
   from scipy.optimize import linear_sum_assignment
   import numpy as np

   def continuous_f1_edges(
       gold: OntologyGraph,
       pred: OntologyGraph,
       gold_vecs: Dict[str, np.ndarray],
       pred_vecs: Dict[str, np.ndarray],
   ) -> Tuple[float, float, float]:
       pred_edges = list(pred.edges)
       gold_edges = list(gold.edges)
       n_p, n_g = len(pred_edges), len(gold_edges)

       if n_p == 0 or n_g == 0:
           return 0.0, 0.0, 0.0

       S = np.zeros((n_p, n_g), dtype=np.float32)
       for i, e_p in enumerate(pred_edges):
           for j, e_g in enumerate(gold_edges):
               S[i, j] = edge_similarity(e_p, e_g, pred_vecs, gold_vecs)

       cost = -S  # 最大化相似度 <=> 最小化负相似度
       row_ind, col_ind = linear_sum_assignment(cost)

       matched = np.maximum(S[row_ind, col_ind], 0.0)
       soft_tp = float(matched.sum())

       prec = soft_tp / (n_p + 1e-9)
       rec  = soft_tp / (n_g + 1e-9)
       f1   = 2 * prec * rec / (prec + rec + 1e-9)
       return prec, rec, f1
   ```

## 【七、Graph F1 指标（节点级 + graph-aware embedding）】

1. Graph F1 的思路：

   * 在节点文本 embedding 的基础上，做若干轮图平滑 / graph convolution，让节点向量融合邻居信息；
   * 然后对 gold 节点和 pred 节点做节点级 Hungarian 匹配；
   * 用匹配的相似度和作为 soft TP，定义节点级 precision, recall, F1。

2. 图平滑函数可以用一个简单的 “均值邻居 + 残差” 的无参数 GCN：

   ```python
   def graph_smooth(
       onto: OntologyGraph,
       base_vecs: Dict[str, np.ndarray],
       K: int = 2,
       alpha: float = 0.5,
   ) -> Dict[str, np.ndarray]:
       # 初始化
       h = {nid: base_vecs[nid].copy() for nid in onto.nodes}
       adj = {nid: [] for nid in onto.nodes}
       for e in onto.edges:
           # 这里可以视为无向图做邻居聚合
           adj[e.src].append(e.tgt)
           adj[e.tgt].append(e.src)

       for _ in range(K):
           new_h = {}
           for v in onto.nodes:
               neighs = adj[v]
               if not neighs:
                   new_h[v] = h[v]
                   continue
               neigh_vec = np.mean([h[u] for u in neighs], axis=0)
               vec = alpha * h[v] + (1.0 - alpha) * neigh_vec
               vec /= (np.linalg.norm(vec) + 1e-9)
               new_h[v] = vec
           h = new_h
       return h
   ```

3. Graph F1 实现（节点级 Hungarian）：

   ```python
   def graph_f1_nodes(
       gold: OntologyGraph,
       pred: OntologyGraph,
       gold_vecs: Dict[str, np.ndarray],
       pred_vecs: Dict[str, np.ndarray],
   ) -> Tuple[float, float, float]:
       gold_ids = list(gold.nodes.keys())
       pred_ids = list(pred.nodes.keys())
       if not gold_ids or not pred_ids:
           return 0.0, 0.0, 0.0

       G = np.stack([gold_vecs[n] for n in gold_ids], axis=0)   # (Ng, d)
       P = np.stack([pred_vecs[n] for n in pred_ids], axis=0)   # (Np, d)

       S = P @ G.T   # (Np, Ng) similarity matrix
       cost = -S
       row_ind, col_ind = linear_sum_assignment(cost)

       matched = np.maximum(S[row_ind, col_ind], 0.0)
       soft_tp = float(matched.sum())

       prec = soft_tp / (len(pred_ids) + 1e-9)
       rec  = soft_tp / (len(gold_ids) + 1e-9)
       f1   = 2 * prec * rec / (prec + rec + 1e-9)
       return prec, rec, f1
   ```

4. 在 `main()` 中：

   * 先对 gold/pred 节点做文本嵌入；
   * 再调用 `graph_smooth` 得到 graph-aware embedding；
   * 再调用 `graph_f1_nodes` 得到 Graph F1。
